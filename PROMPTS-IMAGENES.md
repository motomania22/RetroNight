# Prompts para generar las fotos de cada bebida

Usá cualquier IA de imágenes (Midjourney, DALL-E, Ideogram, Gemini, etc.). Generá una imagen por vez, copiando el prompt específico de cada producto. Todos comparten el mismo estilo base para que la carta se vea uniforme.

## Estilo base (ya incluido en cada prompt)

Fondo blanco puro o transparente, iluminación de estudio tipo publicidad de bebidas, ángulo frontal ligeramente cenital, foto nítida y realista, sin texto ni logos inventados, sin marcas de agua, composición centrada, formato cuadrado 1:1, alta resolución.

## Después de generar cada imagen

1. Descargala.
2. Si el fondo no salió transparente, sacale el fondo con una herramienta tipo remove.bg (opcional, pero se ve mejor sobre las tarjetas oscuras del sitio).
3. Guardala en `public/products/` con el **nombre exacto** indicado en cada prompt (ya está cargado en `products.json`, así que en cuanto pongas el archivo con ese nombre, aparece solo en la web).
